## 2. Student Data Privacy & UK GDPR Compliance (Zero-PII Guarantee)

This application was designed from the ground up with **Privacy by Design** in compliance with the **UK General Data Protection Regulation (UK GDPR)**, the **Data Protection Act 2018**, and the **ICO Age Appropriate Design Code (Children's Code)**:

1. **Zero Personal Identifiable Information (Zero-PII):** The application does not request, collect, process, transmit, or store any personal data of students, teachers, or parents (no names, no email addresses, no logins, no school IDs, no IP logging, and no user accounts).
2. **Zero Cookies, Zero Analytics & Zero Sensor Permissions:** There are no tracking cookies, third-party analytics scripts, telemetry beacons, advertising networks, or device media/sensor permissions in this software.
3. **100% Local Browser Storage (`localStorage`):** Anonymous revision progress (Score Cards) is stored exclusively inside the user's own local web browser (`window.localStorage` under `SHINOBI_SCHOOL_EDITION_V1_PROGRESS`). It never leaves the user's device and can be erased immediately with a single click using the in-app **"🗑️ Clear Local Data"** button.
4. **Standalone Local Mode by Default:** By default, the application executes 100% locally in the browser without opening any external WebRTC or MQTT connections.
